## Compatibility and decisions

- The coordinator approved compatible tooling versions instead of absolute latest where required. Vitest 5 and jsdom 30 exclude Node 25 in their engines, so Vitest 4 and jsdom 29 were selected. Current typescript-eslint supports TypeScript below 6.1, so TypeScript 6.0.3 was selected instead of 7.0.2. The latest Next.js ESLint plugins declare support through ESLint 9, so ESLint 9.39.5 was selected instead of 10.12.0. No remaining Node 25 runtime failures were observed with these pins.
- Internal libraries expose ESM TypeScript source through workspace exports and Next.js transpiles them. This avoids unused library build tooling in the initial skeleton.
- Shared ESLint TypeScript rules apply only to TypeScript files; JavaScript configuration files use the JavaScript rules plus the applicable Next.js configuration.
- Supabase factories validate only public URL/anon-key configuration, and the server factory accepts a request-scoped cookie adapter without importing Next.js. Environment validation and adapter forwarding have tests.
- Type generation invokes the installed Supabase Node shim without shell redirection. It writes UTF-8 only after successful generation and leaves the previous file intact on failure.
- The web development command starts Next.js; Supabase is started separately using the setup steps requested for this task. Turbo forwards public Supabase environment variables to dev/build and hashes local environment files for build caching.
- Next.js generates `next-env.d.ts`; it is ignored in Git and regenerated by the typecheck/build/development commands. Protected documentation and generated database types are excluded from formatting.
- Domain, UI tokens and Supabase are source packages; mobile remains an H11 placeholder. The local seed is empty and the pgTAP test is deliberately trivial until the schema task adds business tables and isolation tests.

No blockers remain for T1. Later tasks own schema, real design tokens, layouts, authentication, i18n, CI and native mobile implementation.
